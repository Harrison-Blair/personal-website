# Personal Website

Bare Next.js app with the App Router, TypeScript, and Tailwind CSS.

```bash
npm install
npm run dev
```

Open http://localhost:3000. Edit `src/app/page.tsx` to build the homepage.

```bash
npm run lint
npm run check
npm run check:fix
npm run format
npm run build
npm start
```

Biome handles linting and formatting. `check` verifies lint rules, formatting,
and import order; `check:fix` applies safe fixes, and `format` formats files.
